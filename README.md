## 📋 Sobre o projeto

O **ICE LOUNGE** é um protótipo de cardápio digital desenvolvido como projeto acadêmico.

A proposta é apresentar os produtos de uma adega/lounge de forma moderna, organizada e responsiva, permitindo que o usuário navegue pelas diferentes categorias diretamente pelo navegador.

O projeto foi desenvolvido com foco em **interface, organização das informações, responsividade e experiência do usuário**.

---

## ✨ Funcionalidades

* ❄️ Interface inspirada na identidade visual da ICE LOUNGE
* 📱 Layout responsivo para diferentes tamanhos de tela
* 🥤 Categorias organizadas de forma intuitiva
* 🍹 Seção de bebidas
* 🥃 Seção de combos
* 🥂 Seção de copos
* 🌙 Seção Lounge
* ⚡ Navegação entre categorias sem recarregar a página
* 🎨 Design moderno com tema escuro e detalhes em azul-gelo
* 💻 Funcionamento diretamente pelo navegador

---

## 🗂️ Categorias

### 🧊 Bebidas

Inclui diferentes opções de bebidas e caipirinhas, apresentadas com seus respectivos preços.

### 🥃 Combos

Apresenta os combos disponíveis, organizados de acordo com as opções de acompanhamento.

### 🍸 Copos

Lista as opções de bebidas servidas em copos, incluindo suas respectivas variações.

### 🌙 Lounge

Área destinada aos produtos relacionados ao espaço Lounge.

## 🎨 Identidade visual

O projeto utiliza uma identidade visual baseada em:

* Fundo escuro
* Tons de azul-gelo
* Elementos inspirados em gelo/cristal
* Tipografia moderna
* Contraste entre textos claros e fundo escuro

A interface foi desenvolvida para transmitir uma estética moderna e relacionada ao conceito de **ICE LOUNGE**.

---

## 📱 Responsividade

O cardápio foi desenvolvido para se adaptar a diferentes dispositivos:

```text
💻 Desktop
   ↓
📱 Smartphone
   ↓
📟 Tablet
```

Dessa forma, o usuário pode acessar o cardápio por computador, celular ou tablet.
